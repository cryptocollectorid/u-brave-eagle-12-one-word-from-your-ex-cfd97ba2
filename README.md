## One Word From Your Ex

Entrants send exactly one word their ex would use to describe them. The
funniest, most painfully honest word takes the whole reward.

This entry's word: **avoidant** — the word every ex reaches for in 2026:
painfully honest, instantly relatable, and the entrant plainly knows it.

## How it works

`main.py` writes exactly one word to `/output/entry.txt` and prints it.
The gate requires UTF-8 text of 1–24 characters, not only white space.

```sh
python3 main.py
cat /output/entry.txt
```
